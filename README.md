# Emotsiya - Building Great Citizens. Building a Great Nation.

Emotsiya is India's National Civic Education & Human Development Initiative. This web application provides an interactive platform for youth leadership, school integration, community action drives, event pass enrollment (₹199 & ₹499 passes), and real-time WhatsApp integration.

---

## 🌟 Key Features

- **Interactive Visual Banner**: Dynamic campaign slide switcher with high-resolution photography, live metrics, and instant dual pass selector.
- **Dual-Direction Scroll Reveal**: Smooth 60fps hardware-accelerated fade-in transitions when scrolling up and down.
- **7 National Challenges Hub**: Photographic module cards covering Crime Reduction, Pollution Control, Drug Prevention, Traffic Safety, Cleanliness, Social Connection, and EQ Wellness.
- **6-Step Transformation Approach**: Visual 6-step roadmap (Learn, Experience, Practice, Connect, Transform, Lead).
- **Life Skills Matrix**: Image-backed masterclasses for employability, leadership, public speaking, and emotional intelligence.
- **Event Hub & Pass Enrollment**: Active tabs for Live, Upcoming, and Past events with pre-filled WhatsApp enrollment link generator for ₹199 (Standard) and ₹499 (VIP Leader) passes.
- **Media & Impact Gallery**: Filterable photo gallery with full-screen Lightbox modal.
- **WhatsApp Integration**: Floating quick-chat support widget and pre-filled inquiry triggers linking directly to `+91 88080 37280`.

---

## 🛠️ Technology Stack

- **Framework**: React 18 with TypeScript & Vite
- **Styling**: TailwindCSS & Custom Liquid Glass System
- **Icons**: Lucide React & Official WhatsApp Brand SVG
- **Animations**: Custom `IntersectionObserver` React hook with hardware-accelerated CSS composition

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

The application will start on `http://localhost:3000`.

### Production Build

```bash
npm run build
```
